# Alkolender

Øljulekalenderen: én øl om dagen i december, ratet 0–5 i kvarte point.

Siden ligger på https://helmermis.github.io/alkolender/.

`index.html` bygges af `build.py` (i Dropbox, ved siden af `Julekalender data.xlsx`) med `python build.py --publish`. Ret ikke filen her direkte.
Det levende år registreres på siden og gemmes i Firebase (projektet `alkolender-jul`).
